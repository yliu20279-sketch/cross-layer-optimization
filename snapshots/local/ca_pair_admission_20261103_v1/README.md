# 两模型 CA 小规模准入准备

pair.json 按模型分别实例化。所有 null 须绑定实物 SHA 后才可运行。候选沿用 16 节点、host128 GiB/HB8 GiB，实际后端参数待统一。共同快照包含原始页映射、KV、缓存、队列和 HiBand 状态。请求清单固定 token、到达时刻、请求归属、prefill/decode、停止规则及种子。两臂各自恢复同一快照，唯独切换 CA；策略及预算事先冻结。

先验收两模型实际重叠执行、请求归属、KV 隔离和独立数值对照。至少两个不同请求交错执行 prefill 和 cached decode，对各自独立参考检查输出、路由和 KV，并保留跨请求读写拒绝证据。随后每模型取一个已见 DEV 请求组，验证 B、CA 身份映射、CA 合法迁移和非法映射拒绝。身份映射及负对照单列。正式性能矩阵暂停。

每臂保存退出状态、命令、环境及输入哈希。请求记录保存请求 ID、归属、到达及完成 tick、输出/路由/KV 哈希；事件记录保存事件 ID、依赖、请求 ID、时钟域、起止 tick、物理地址、页代际、读写字节和回执。决策、排空、迁移读写、提交、回收和请求完成须在因果链上可查。校验逻辑负载守恒，分别汇报迁移读字节、写字节、暂存峰值及容量余量。失败和零收益均保留。

主指标为同一目标时钟下从固定观测起点至最后请求完成的跨度，在线决策和迁移的阻塞与资源竞争由执行时钟承担。事件时长单列，重叠部分不重复加到完成跨度。离线采集、建图及求解记录主机墙钟、峰值内存和复用次数。时钟转换或成本接入未闭合则不计算净收益。范围只有层时只报层跨度。净下降为 (B−CA)/B，加速比为 B/CA。

当前依据为 261102 的两模型计划 v4 和 P0-1b v5 REPORT。v5 为串行单层，固定两页交换，官方 CPU 对照仍有差异，不能作准入回执。
