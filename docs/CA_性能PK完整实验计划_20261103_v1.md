# CA 性能 PK 完整实验计划（2026-11-03）

## 研究问题与范围

在共同平台的 Sem-MoE＋HiBand 独立重建基线 B 上，评估 CA 计入决策及物理页迁移后的净收益。Qwen3-30B-A3B 使用 BF16，保留既有 FP32 累加边界。Qwen1.5-MoE-A2.7B 使用 Chat-GPTQ-Int4 checkpoint 离线解码 FP16，保留 FP32 K64 分块合同，论文披露权重来源。两个模型分别验收和统计。

## P0-1b 并发与正确性

v5 仅覆盖串行单层、prefill 1 token、cached decode 1 token 和固定两页交换。实际 DRAM/NoC 与数值路径已经接通，官方 CPU 对照仍有差异。两模型分别在同一后端实际交叠执行至少两个不同请求，覆盖 prefill 与 cached decode。记录请求归属、KV 分配/追加/读取/回收，加入跨请求读写拒绝及未完成写回拒绝。以独立参考核对输出、路由槽位及权重、KV 和关键中间量，定位首差并预先冻结判据。检查实际页迁移回执、代际、提交及旧读者排空。统一 256 B 诊断事务与目标平台参数，验证 CPU/PCIe/缓存维护成本和时钟，覆盖目标 PP、多层与分页生命周期。

冻结 checkpoint、tokenizer、运行入口、库、精度、TP/EP/PP、专家放置、拓扑、时钟和 DRAM/NoC/PCIe 参数。候选 16 节点、host 128 GiB、HB 8 GiB。容量包含权重、KV、激活、工作区、元数据和迁移暂存。两模型各交付独立审核回执。

## P0-2 小规模准入

每模型选择一个已见 DEV 请求组。固定 token、到达序列、初始页映射、KV、缓存、队列、HiBand 状态、调度规则和种子。各臂独立恢复相同快照，主对照只切换 CA。检查 B、B＋CA 身份映射、B＋CA 合法迁移以及非法映射拒绝。逐项核对逻辑输出、路由、KV、计算和通信负载守恒。非法映射不可部分提交。迁移读写、物理地址、页代际、回执及新地址消费须可追踪。绑定配对模板中的身份哈希；准入周期单列。

## P1 面板冻结和主对照

DEV 先定位 B 的关键路径 Bank 暴露等待。若争用改善被重叠或瓶颈转移抵消，保留负例；若未发现可利用空间，暂缓扩矩阵。面板覆盖短问答、多轮和长上下文。按源文档/对话及完整 token 序列去重，分 profile、DEV、TEST。已见样本只进入 DEV。用 DEV 波动确定样本量，查看 TEST 前冻结版本、样本 ID、长度分层、到达时刻、并发、种子、输出预算和 EOS。主对照 B vs B＋CA，附加 DEV 冻结的强固定布局。冻结策略、预算、执行顺序方案及判据，完整保留逐组结果与失败。

## P2 机制、规模与成本

比较 CA、仅热度、打乱共访边、至少五个预注册种子的匹配随机布局。尽量匹配改动字节、容量、热度；检查地址变化、Bank 争用、关键路径等待和完成时间。容量合法后比较 4/8/16 节点、单请求与并发、上下文长度。同规模配对并声明固定总资源或每节点资源。页粒度、可移动比例、画像年龄、优化预算先做单因素；超容量记 INFEASIBLE。

在线决策、排空、迁移读写、提交、回收及资源竞争进入同一执行时间线。记录起止 tick、时钟域、依赖、请求归属、迁移字节、峰值暂存、失败代价和暴露开销，避免重复计入重叠时间。离线采集、建图、求解与安装记录主机墙钟、峰值内存、元数据及复用次数。主机时间与目标时钟有部署换算后才算合并盈亏平衡。

## P3 指标、统计及交付

主指标是同一目标时钟从固定起点至最后请求完成的跨度。净下降 (T_B−T_CA)/T_B，加速比 T_B/T_CA。请求组为独立单位，分模型报告配对分布、置信区间、最差退化、零收益、失败和不可行。层/token/确定性重复不扩大样本量。暂定净收益至少 1%、最差退化至多 1%，运行前冻结聚合口径。连续层只报层跨度；完整请求及排队、计时闭合后再报 TTFT、TPOT、吞吐和尾延迟。

交付冻结合同、逐组原始结果、成本账本、失败日志、索引和独立复核回执。旧结果单列；P0-1b、P0-2 通过后才启动正式性能矩阵。
