# 场景一｜固定 Mesh RTL 可行性验证

这批实验比较固定 Mesh XY 与基于现有 CS 路径的配置算法，用于验证算法能否生成、提交并执行分流，以及归因通算与 MoE 的竞争。**论文正式主性能基线为 HiBand，HiBand 的同口径配对待完成。** 所有结果均为单层 RTL 回放，GetS 为合成事务。

| 归档 | 证据范围 |
|---|---|
| [单 Agent 配对](single-agent-20261115/) | 一个通算事务源、一个 6 核 MoE、第 0 层，共 10 组，含单跑和错峰。继承到达计划的 6 组持平；4 个合成重叠用例中有 2 组通算后继提前。 |
| [双 MoE 扩展](extensions/dual-moe-fixed-mesh-20261115/) | 14 组双 MoE 固定 Mesh 配对，含忙态基线和两侧完整方案。结果只用于多负载环境的扩展验证。 |
| [算法消融](extensions/algorithm-ablation-20261115/) | 原论文算法、仅改候选、仅改提交判据、同时修改。该消融保留当前配置作为共同参照，部分忙态参照上有旧 CS 活动。 |

每个目录提供结果表、逐事务记录、原始归档和 SHA-256。单 Agent 目录还提供逐消息、逐出口和选路记录。各压缩归档包含复跑脚本、输入和 RTL 日志。
